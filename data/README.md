## The model's inputs

One file of each kind per year. These are what `core_model/empirical_data.py` reads.

| File | What it holds | Where it comes from |
|---|---|---|
| `party_positions_{year}.csv` | each candidate's left-right position, 0–10, and its source | respondents' placements: CSES 2002, Ipsos–CEVIPOF 2022; six minor 2002 candidates imputed |
| `voters_ideology_{year}.csv` | how voters place themselves, 0–10 | CSES self-placement |
| `polls_{year}.csv` | every first-round poll in the window | French Wikipedia poll lists, at fixed revisions |
| `results_{year}.csv` | first- and second-round results | Ministère de l'Intérieur |

Positions and electorates are explained in [`cses/`](cses/README.md), polls in
[Experiments → Data sources](../docs/experiments.md#data-sources).

## Folders

| Folder | What it holds |
|---|---|
| [`cses/`](cses/README.md) | How the positions and electorates are built from the surveys, every specification, and their limits. |
| [`ipsos/`](ipsos/README.md) | The Ipsos–CEVIPOF 2022 candidate placements, transcribed from the published report. |
| [`previous_inputs/`](previous_inputs/README.md) | The inputs of the August 2026 run, kept so it stays reproducible. |
| `raw/` | Downloaded CSES files and cached Wikipedia pages. Not committed: CSES data may not be redistributed. |
| `archive/` | Checksummed copies of earlier runs' outputs. Not committed. |

## Other files

| File | What it holds |
|---|---|
| `polls_dropped.csv` | The two 2002 polls left out because they did not offer every candidate. |
| `saltelli_results_K{6,8,9}.csv` | Raw output of the synthetic sensitivity analysis, kept so its indices regenerate. |
| `FR-electoral_data.csv`, `FR-vote_transfers.csv` | Polls, results and second-round transfers for five elections, used only by the explanatory figures. |

Everything else in this folder, the raw output of the empirical runs, is regenerated by the pipeline and is not
committed.

<details>
<summary><strong>Rebuilding the inputs</strong></summary>

<br>

```bash
python tools/build_polls_from_wikipedia.py --force      # polls, from the pinned revisions
python tools/build_cses_inputs.py --force               # positions and electorates; needs data/raw/cses/
cp data/cses/party_positions_{2002,2022}.csv data/cses/voters_ideology_{2002,2022}.csv data/
```

Both scripts refuse to overwrite without `--force`. The CSES files have to be downloaded first; see
[`cses/README.md`](cses/README.md#sources).

</details>
