The research question

Under a two-round runoff, a voter whose preferred candidate cannot reach the runoff faces a choice: vote sincerely and risk having no representative in round two, or switch to a compromise candidate who can qualify. When does that individual incentive aggregate into visible coordination, and when does it fail?

France 2002 is the canonical failure: the left vote split across several candidates and the Socialist front-runner missed the runoff. France 2022 is the contrasting case, with visible consolidation around a few candidates.

Scope

The model covers the first round only. Round two is never simulated. It enters solely as a projection voters form about who will qualify. There is no campaign, no turnout decision, no abstention, and no candidate entry or exit.

The distinction matters throughout: in empirical mode the signal is read from data rather than generated, so every signal-generating parameter is inert.

Scope

The empirical mode is pattern-oriented. One behavioural draw is applied to both years, only the environment changes, and nothing is fitted to either election. Where the model diverges from the real result, the divergence is recorded as it stands.

Public signal

A single shared vector st over the K candidates, summing to 1. Every voter sees the same signal, and there is no private information channel.

One complete iteration

The loop runs to max_iterations: T = 25 in synthetic mode, the length of the real poll sequence in empirical mode. Iteration 0 is the sincere allocation and carries no strategic step, which is why history has n+1 entries while the diagnostic series have n.

That offset is real and intended. The test pinning it, test_the_histories_line_up_on_the_documented_offset, was written after investigating an apparent failure, so it documents the structure rather than asserting a convenient falsehood.

Initialization

At iteration 0 every voter is assigned an attachment j*, the party they express by default.

nearest
deterministic

j* = argmaxj ua(j), simply the closest candidate. One vote each, no randomness.

probabilistic
salience × ideology

Pa(j) ∝ saliencea,j · exp(−β(xa − xj)²) for j ∈ Ca.

The nearest rule is pathological on real candidate sets

Because it looks only at distance, it hands enormous shares to whichever candidate happens to sit in a dense ideological region regardless of viability. It is retained as the baseline specification precisely because that failure is informative.

Parameters of the probabilistic rule
ParameterRole
β ≥ 0ideological sharpness. β = 0 → salience alone, ideology drops out. β → ∞ → all mass on the nearest contender, recovering the nearest rule.
salience_source="signal"salience = the opening poll s0
salience_source="prior"salience = the voter's prior πa ~ Dirichlet(ρπ·s0)

Both β limits are pinned by analytic tests, so a β effect in the sweeps is interpretable rather than a black box.

Fixed-seed stochasticity

Every stochastic step draws from a seeded numpy.random.Generator. Same seed → bit-identical output, including the voter sample, the priors and the attachment draws. Per-run seeds in the sweeps are derived deterministically:

run_seed = seed + 1000 * (draw + 1) + repeat

so a resumed run reproduces an uninterrupted one exactly.

Tolerance: the two units

Most error-prone quantity in the project

Two different things are called "tau". Confusing them silently disables the entire strategic mechanism, which is exactly what happened, and what the 2026-08-21 rerun corrected.

SymbolUnitsWhere used
Normalisedτ̂ tau_hatzone lengthsthe design variable, what every sweep draws and every CSV records
Absoluteτ tauideology units on [−1, 1]what run_simulation(tau=…) actually consumes

They are related through the zone length ℓ = 2/K:

τ  =  τ̂ × (2 / K)

Why the absolute value differs between the two years

K is the number of candidates, and it differs by year: 15 in 2002, 12 in 2022. One shared τ̂ draw therefore maps to a different absolute tolerance in each year:

τ̂→ τ in 2002 (K=15)→ τ in 2022 (K=12)
0.50.0670.083
1.50.2000.250
3.00.4000.500

That is what τ̂ is for: it stays comparable across party systems of different size, which is exactly what a two-election comparison needs.

Where the conversion occurs

Exactly once, in core_model/metrics.py:

def zone_length(K: int) -> float:
    return 2.0 / K

def tau_absolute(tau_hat: float, K: int) -> float:
    return tau_hat * zone_length(K)
What goes wrong without it

Passing τ̂ straight through silently reinterprets it as an absolute distance. At τ ≥ 2 every party is a contender for every voter, so Ca ∩ TR = ∅ never holds, the trigger never fires, and the strategic module is inert.

That defect affected all pre-2026-08-21 empirical results, where 40 % of the design sat at τ ≥ 2 outright. The model emits a UserWarning at τ ≥ 2; the corrected run's 30 simulation logs contain zero occurrences.

Every empirical replay and sweep row carries tau_hat, tau_absolute and K, so the relation is checkable from the CSV alone with no knowledge of how it was produced. tools/validate_rerun.py enforces it to 1e-12.

One intentional exception

initialization_benchmarks() passes tau=2.0 in absolute units deliberately, so that every party is a contender. Those benchmarks compare the three attachment rules on identical footing; restricting the contender set would confound the rule being measured with the size of Ca. This is not a swept draw, and it is commented as an exception at empirical_2002_2022.py:511.

Signals and belief updating

Synthetic generated signals

s̃i = (δi + εs)1/θ ⁄ Σj (δj + εs)1/θ,   s ~ Dirichlet(ρs · s̃)
ParameterMeaning
θ thetasignal temperature. θ < 1 sharpens viability gaps; θ = 1 faithful; θ > 1 compresses them.
ρs rhoDirichlet precision. Higher is less noisy.
εs signal_epsilonnumerical floor so a zero-support party still gets strictly positive concentration. Default 1e-12.
εs = 1e-12, not 1e-4

The floor is a numerical guard with no smoothing role. Earlier documentation quoted 1e-4; that value is obsolete. The current default is at model.py:100 and is pinned by tests/test_signal_epsilon.py (25 tests).

Empirical exogenous poll timelines

The signal sequence is the real poll timeline, with no generation step. Weekly means by default; individual polls as a robustness variant. max_iterations equals the length of that sequence.

Belief update

t = 0: m0a = πa   ·   t > 0: mta = α · πa + (1 − α) · st

The previous posterior is never reused. Inertia is anchored to the fixed prior πa rather than to an evolving belief state. At t = 0 the posterior is set to πa directly, avoiding double-counting s0, which already generated πa.

Which parameters are inactive in empirical replay

Because the signal is read rather than generated, these have nothing to do:

Inert in empirical modeWhy
θ temperatureno transformation is applied to a real poll
ρs signal precisionno Dirichlet draw is taken
εs signal flooronly used inside signal generation
ξ skew, c widththe electorate is sampled from real data
εF floor weightbelongs to the generated electorate mixture

The behavioural sweep deliberately excludes ρs as a placebo dimension for exactly this reason. Active parameters in empirical mode are τ̂, μ, α, ρπ and, under probabilistic initialization, β.

Strategic choice

Contender set

Ca = { j : |xa − xj| ≤ τ }

The boundary is inclusive. Two guarantees hold by construction: the sincere choice j* is always in Ca, and Ca is never empty.

Viability and the trigger

Each voter ranks candidates by their own posterior belief and projects the top Krunoff (= 2 for a presidential election) as the qualifiers.

Ga = 1  iff  Ca ∩ TR = ∅

In words: the voter has a strategic incentive only when none of the candidates they can tolerate is projected to reach the runoff. If a contender is projected to qualify, the voter's bloc already has a representative and they vote sincerely. This depends on the projection, not on preference intensity.

Expressive-cost comparison

When Ga = 1, the voter maximises over j ∈ Ca:

φa(j) = LVa,j · NVa,j,k* − μ · λ̂a(j)
TermDefinition
LVa,jlocal viability, ma,j renormalised over Ca
NVa,j,k*projected runoff share of j against the strongest opponent k*
λ̂a(j)expressive cost, (ua(j*) − ua(j)) / ℓ² ≥ 0
μloyalty weight. μ = 0 → pure instrumental choice; large μ pins the voter to j*.

No penalty is charged on j = j*. The cost is normalised by ℓ² = (2/K)² so μ stays comparable across party systems of different size, for the same reason as τ̂.

Switching and conditional switching

RateDefinition
trigger rateshare of voters with Ga = 1
switching rateshare of all voters who end up away from j*
conditional switchingshare of triggered voters who actually switch

The third separates the pressure layer from the behavioural layer: a high trigger rate with low conditional switching means the incentive exists but μ or the viability terms suppress action.

Outcome measures

ENP(δ) = 1 ⁄ Σj δj²   ·   CENP(δ) = (K − ENP(δ)) ⁄ (K − 1)

ENP is the standard Laakso-Taagepera index: an electorate split evenly across 4 candidates has ENP = 4. CENP rescales it so 0 = maximal fragmentation and 1 = full coordination, making different K comparable.

Two ΔCENP baselines that must never be mixed

The project uses two different ΔCENP definitions, deliberately, and they are not equal.

BaselineComparable to observation?
Replaythe model's own iteration-0 sincere shares
functions.coordination_measures(sincere, final)		No
Sweepthe exogenous opening poll s⁰
cenp(final) − cenp(s⁰)		Yes

The observed target is CENP(actual result) − CENP(s⁰), so only the sweep definition may be compared with the real election. The two are intentionally left as separate implementations. A contract test pins them against drift and deliberately does not assert they are equal.

Candidate-level outcomes and cliff statistics

Per candidate: mean final share with a p05-p95 band, change from the first signal, and top-k membership probability.

Top-k accuracy is an exact set match: 1.0 only if the simulated top-k set equals the actual top-k set, 0.0 otherwise. It is not a partial-credit measure, which is why values of exactly 0 are common.

The "cliff" is the largest gap in the sorted share vector, the point separating viable from non-viable candidates. cliff_magnitude is the size of that gap, cliff_location the rank where it falls, cliff_ratio the share mass above it. A sharp cliff means a clear viability boundary; a flat profile means none.

Why golden-value regressions exist

Comparing two runs of today's code only catches divergence between argument paths. A change that moves every path equally, such as a rewrite of the sincere-init rule or a reordering of RNG draws, leaves such a test green while every published number changes. Golden values are what the suite remembers about earlier commits.

A failure is either a bug, in which case fix the code and not the numbers, or a deliberate model change, in which case re-record with the snippet in each docstring and say so in the commit message. Every figure generated before that commit is then stale.

Where the metamorphic properties come from

Candidate-relabelling invariance and left-right reflection symmetry were derived from the equations before anything asserted them. All 120 relabellings were exhaustively verified, and reflection was checked at five voter positions. Both hold with no counterexample. Had one failed, the contract itself would have been the thing in question, ahead of the code.

The incident behind output-isolation testing

On 2026-08-19 a 15-draw --quick run silently overwrote the full 300-draw main-replay outputs, which had never been committed (data/ is git-ignored). Recovering them would mean regenerating from the pre-fix commit. The protection was written so it cannot recur: quick mode writes to a separate directory, which makes the dangerous case unrepresentable rather than merely discouraged.

Panel C, read its claim precisely

Panel C evaluates six signal_epsilon values across four selected parameter configurations. It establishes local robustness for those tested configurations, not invariance across the full Saltelli parameter space.

The grid is εs ∈ {1e-12, 1e-6, 1e-4, 1e-3, 1e-2, 1e-1} × {Baseline, Sweet-spot} × {θ = 0.3, θ = 1.0}, 10 repetitions each, giving 24 rows in robustness_panel_C.csv. Within those configurations, 1e-12, 1e-6 and 1e-4 return identical voting outcomes.

These numbers are a regeneration. In the panel's original form εs never reached the simulation, so every grid point was bit-identical and the invariance it appeared to show was vacuous; earlier copies of this panel disagree with the committed one.

What the protocol constants are, and are not, justified by

ConstantJustified byClaim it supportsClaim it does not support
N = 2000 voters Panel A The standard error of ΔCENP across seeds has stabilised by N = 2000, which is an estimator-stability criterion. That any single run is accurate, or that a mean at N = 2000 equals the limit.
Tmax = 25 iterations Panels B + G The mean across seeds is robust to the ceiling: extending to T = 60 moves it 0.3 % for ΔCENP and 0.04 % for final ENP. That the dynamics converge. Panel B shows the diffuse regime (c = 2.5) never reaches a fixed point: 70 % of runs are still moving at the ceiling, and a single run's outcome moves by more than the between-seed SD (drift_over_sd ≈ 1.2-1.4).

Aggregate results are robust to the T = 25 ceiling, while individual trajectories are not. A flat claim that the model converges by T = 25 is unsupported by these panels.

Canonical CSV serialisation

Finalising a sweep file reads it and writes it back, so it has to be a fixed point: finalising twice must produce the same bytes as finalising once. Otherwise a resumed run and an uninterrupted run yield different files from identical numbers.

CI caught a failure on 2026-08-22 that came from the reader rather than the writer. pandas' default float parser is fast but not correctly rounded, so it can return a double one ulp from the value the text denotes. Reading with float_precision="round_trip" fixes it at source. Three writer representations were measured on 60 000 adversarial doubles in both dependency environments. repr as a callable is rejected (under numpy 2 it emits np.float64(0.1)), "%.17g" is rejected (it writes -0.0 as -0, losing the sign of zero), and pandas' default shortest round-tripping form is bitwise exact throughout.

Warning policy

The suite runs clean. Filters live in pytest.ini and no category is ignored wholesale. Every entry pins a specific message and, where possible, the module that raises it, so a new warning of the same category still surfaces.

Numerical warnings are promoted to errors (error::RuntimeWarning). An overflow, an invalid value or a divide-by-zero inside the model changes results, so it should stop the suite rather than print a note. The suite emits none, so this costs nothing and catches the next one.

Empirical replay and sweep

Replay sweeps tau_hat [0.5, 3.0], rho_pi [5, 200], alpha [0, 0.9], mu [0, 1.0], plus beta [0, 20] under probabilistic initialization. The behavioural sweep uses the same five, Latin-hypercube sampled, 1 000 draws × 4 repeats per year.

Because τ = τ̂·(2/K), the effective tolerance is ≤ 0.400 in 2002 and ≤ 0.500 in 2022.

Installation

The two Latin-hypercube declarations

The function bodies are identical; the dimension orders are not, and empirical_2002_2022 uses tau_hat, rho_pi, alpha, [mu], [beta] while behavioral_sweep uses tau_hat, mu, alpha, rho_pi, beta.

The LHS routine draws one dimension at a time from a shared generator, so the order determines the design. Reordering the list changes every drawn value and would silently invalidate the comparison the reruns exist to produce. The function may be lifted; the orders must not move.

The two ΔCENP definitions are likewise separate by design, as is initialization_benchmarks passing tau=2.0.
