# Result tables — registry

Compact, reproducible tables carrying the numbers behind the analysis. This file
is a **registry**: for each table, what it contains, what generates it, what it
consumes, how to rebuild it, and any qualification on reproducing it.

Model explanation lives in [`docs/model.md`](../docs/model.md); the verification
record in [`docs/validation.md`](../docs/validation.md); experiment protocols in
[`docs/experiments.md`](../docs/experiments.md). None of that is repeated here.

Raw simulation output (`data/empirical_*`, `data/behavioral_*`,
`analysis/**/outputs/`) and all figures stay **intentionally uncommitted** — they
are bulky and regenerate from a seed. Only `results/tables/` is tracked.

---

## Formal versus exploratory

One distinction is load-bearing and easy to lose:

| Table | Status | What it licenses |
|---|---|---|
| `sobol_indices.csv` | **Formal variance decomposition** — Saltelli design, Sobol estimator, bootstrap CIs | "Parameter *x* accounts for *n* % of the variance in outcome *y*." |
| `robustness_panel_*`, `protocol_*` | Descriptive summaries of designed experiments | "Under condition *x*, the statistic is *y*." |
| `lhs_parameter_importance.csv` | **Exploratory surrogate importance** — LHS design, RandomForest, permutation importance | "Parameter *x* ranks above *y* for this outcome." **Not** a variance share. |

The LHS design is not a Saltelli sequence, so those importances rank parameters;
they do not decompose variance.

## Empirical tables

Derived from the empirical rerun of 2026-08-21 (commit `0bba146`, 14 000
simulations — see the
[rerun record](../docs/reports/empirical_rerun_2026-08-21.md)).

| | |
|---|---|
| **Generated by** | `analysis/empirical/make_empirical_tables.py` |
| **Inputs** | `data/empirical_*.csv`, `data/behavioral_sweep_*.csv`, `data/behavioral_targets.csv` (generated, git-ignored) |
| **Regenerate** | `python analysis/empirical/make_empirical_tables.py` |
| **Tests** | `tests/test_empirical_tables.py` |
| **Qualification** | Byte-identical on regeneration from unchanged inputs. A pure function of the raw output: fixed row and column order, no timestamps. |

| File | Rows × cols | Key | Contents |
|---|---|---|---|
| `empirical_replay_summary.csv` | 112 × 12 | `specification, year, metric` | mean / sd / p05 / p50 / p95 of 14 outcome metrics, per specification and year |
| `empirical_robustness_summary.csv` | 84 × 12 | `variant, year, metric` | same statistics for the three perturbation variants |
| `empirical_activation_summary.csv` | 8 × 13 | `specification, year` | mean trigger / switching / conditional-switching rates, and the fraction of draws clearing 1 %, 5 % and 10 % thresholds |
| `behavioral_sweep_quantiles.csv` | 2 × 19 | `year` | sweep ΔCENP distribution (7 quantiles, mean, sd) against the observed target |
| `empirical_year_contrast.csv` | 56 × 10 | `specification, metric` | 2002 vs 2022 means, difference, pooled sd, Cohen's *d* |
| `empirical_candidate_fit.csv` | 108 × 14 | `specification, year, party` | per-candidate simulated vs actual share, error, p05–p95 band, top-*k* probability |

**Specifications** are `nearest` (main replay, 300 draws/year) and the three
probabilistic-initialization variants `prob_signal`, `prob_prior`,
`prob_signal_mu0` (800 draws each). Every table carries `K` (15 for 2002, 12 for
2022) so the τ̂ → τ conversion behind a row is identifiable.

> **The two ΔCENP baselines never mix.** `empirical_replay_summary.csv` measures
> ΔCENP against the model's own iteration-0 sincere shares.
> `behavioral_sweep_quantiles.csv` measures it against the exogenous opening poll
> s⁰ — the baseline the observed target uses, so only that table is comparable
> with the real election. It names its baseline in a `baseline` column, and a
> test pins it.

> `empirical_year_contrast.csv` carries an `effect_size_defined` flag. The top-*k*
> set accuracies are identically zero in both years, so their pooled standard
> deviation is zero and no effect size exists; those rows report `0.0` with the
> flag `False` rather than NaN, keeping the table finite.

## `lhs_parameter_importance.csv`

| | |
|---|---|
| **Contents** | Exploratory parameter importance for ΔCENP under the empirical structure. 15 rows = 5 parameters × 3 scopes (`2002`, `2022`, `pooled`); columns `scope, parameter, permutation_importance, importance_std, relative_importance_pct, standardized_coefficient, cv_r2_mean, cv_r2_std, n_rows, seed` |
| **Generated by** | `analysis/empirical/lhs_importance.py` |
| **Inputs** | `data/behavioral_sweep_{2002,2022}.csv` (generated, git-ignored) |
| **Regenerate** | `python analysis/empirical/lhs_importance.py` |
| **Qualification** | **Reproducible but not byte-identical.** Compare numerically, never by checksum. |

`cv_r2_mean` qualifies every other number in the row: a surrogate that cannot
predict the outcome produces importances that mean nothing. The script warns
below 0.1. The predictor set is declared rather than inferred
(`SWEPT_PREDICTORS`), and all seeds are fixed at `SEED = 42` — the sweeps' own
seed, `20020422`, is a different number belonging to the design.

Values reproduce to within numerical tolerance and rankings exactly.
Last-bit differences (~1e-16) appear between runs because the surrogate is fitted
in parallel and the order of floating-point reduction is not fixed.

> ⚠️ **The `pooled` scope has a cross-validated R² of −0.187** — worse than
> predicting the mean. It should not be cited. The per-year scopes (R² 0.853 and
> 0.991) are sound.

## `sobol_indices.csv`

| | |
|---|---|
| **Contents** | First- and total-order Sobol indices with bootstrap CIs. 120 rows = 3 *K* × 5 outcomes × 8 parameters; columns `K, outcome, parameter, S1, S1_conf, ST, ST_conf, n_base, n_evaluations` |
| **Generated by** | `analysis/synthetic/saltelli_sensitivity.py` |
| **Inputs** | `data/saltelli_results_K{6,8,9}.csv` — **committed** (~2 MB each), holding all 30 720 model evaluations |
| **Regenerate** | `python analysis/synthetic/saltelli_sensitivity.py --analyze-existing` |
| **Qualification** | Runs **no simulations**; recomputes from committed inputs. The only table in this directory reproducible from a fresh clone alone. |

Design: `calc_second_order=False`, so the Saltelli sample is *N*(*D*+2) per *K*.

## `robustness_panel_{A…G}.csv`

| | |
|---|---|
| **Contents** | Protocol robustness panels justifying the fixed simulation constants |
| **Generated by** | `analysis/synthetic/robustness_checks.py` |
| **Inputs** | none — generates its own runs |
| **Regenerate** | `python analysis/synthetic/robustness_checks.py` (all panels) or `--panels A B` |
| **Qualification** | ~1 540 model runs, roughly 2–4 minutes. Panel E is analytic and runs no simulation. Detailed `panel_*_raw.csv` files go to `analysis/synthetic/outputs/robustness_checks/` and stay ignored. |

| Panel | Rows | Varied | Fixes |
|---|---|---|---|
| A | 20 | *N* ∈ {250 … 5000}, 4 width regimes | *N* = 2000 |
| B | 4 | convergence-iteration distribution | *T*<sub>max</sub> = 25 |
| C | 24 | ε<sub>s</sub> ∈ {1e-12 … 1e-1} × 4 configurations | ε<sub>s</sub> = 1e-12 |
| D | 9 | ξ ∈ [−0.75, 0.75] | ξ = 0 |
| E | 56 | θ ∈ {0.3 … 3.0}, analytic | documents θ |
| F | 16 | μ ∈ {0 … 1} | documents μ |
| G | 9 | ceiling *T* = 25 vs 60 | validates *T* = 25 |

Each table carries the varied condition, the fixed regime, the repetition count
and the dispersion statistic, so every plotted point reconstructs from its row.
The tables call the same aggregation functions as the plots, so a row and its
point are computed once, not twice.

> **Panel C — read its claim precisely.** Panel C evaluates six `signal_epsilon`
> values across four selected parameter configurations. It establishes local
> robustness for those tested configurations, not invariance across the full
> Saltelli parameter space. (In its original form the ε value never reached the
> simulation, so all grid points produced bit-identical output; it has since been
> fixed and regenerated.)

> **Panel G qualifies Panel B.** Aggregate results are robust to the *T* = 25
> ceiling; individual trajectories are not. A flat claim that the model converges
> by *T* = 25 is not supported.

## Regenerating without simulating

```bash
python analysis/synthetic/saltelli_sensitivity.py --analyze-existing
```

That is the only table rebuildable from committed inputs alone. Once raw
empirical output exists in `data/`, these two also need no further simulation:

```bash
python analysis/empirical/make_empirical_tables.py
python analysis/empirical/lhs_importance.py
```

Everything else requires its experiment to be run first — see
[`docs/reproducibility.md`](../docs/reproducibility.md).
